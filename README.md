# NUTCRACKER — 클라라의 마법 여행

## 제1장 · 크리스마스 저택

1. 벨벳 커튼이 열리고 내레이션으로 시작해요.
2. 드로셀마이어 아저씨의 선물을 열면 호두까기 인형이 나와 클라라를 따라다녀요.
3. 마법의 별 8개를 모아요. 소파와 찻잔 테이블 위(점프), 트리를 도는 기차 화물칸, 벽난로 선반(알파벳 블록 계단), 오르골·흔들 목마·양말 속(살펴보기)에 숨어 있어요.
4. 자정이 되면 부엉이 시계가 울리고, 트리가 커지고, 호두까기 인형이 사람 크기로 깨어나요.
5. 생쥐 군단 5마리를 슬리퍼로 물리치고, 생쥐 왕의 왕관에 4번 맞혀 별을 되찾아요.
6. 호두까기 인형이 왕자로 변하고, 설탕 요정이 연 별의 문으로 들어가면 제2장이 열려요. (제2장은 아직 없어요.)

## 구조

```
index.html      단독 실행 게임 (빌드 결과)
artifact.html   Claude Artifacts용 본문 (빌드 결과)
src/            원본: js/01-core.js … 11-main.js, style.css, body.html
build.mjs       src/ → index.html, artifact.html
```

수정은 `src/`에서 하고, 아래 명령으로 두 파일을 다시 만들어요.

## 빌드

```bash
npm run build        # 또는 node build.mjs
```

Node.js만 있으면 돼요. 설치할 패키지는 없어요. three.js 0.159.0은 jsDelivr CDN에서, 글꼴은 Google Fonts에서 불러와요.

## 배포 (GitHub Pages)

1. 저장소 **Settings → Pages**
2. **Build and deployment → Source: Deploy from a branch**
3. **Branch: `main`, folder: `/ (root)`** 를 고르고 Save

## 만든 방식

- 캐릭터, 가구, 벽지, 양탄자, 얼굴까지 모두 코드로 그려요. 외부 3D 모델이나 이미지 파일은 없어요.
- 오르골 왈츠, 자정의 행진곡, 효과음은 WebAudio로 합성해요. 샘플 파일은 없어요.
- 정적 소품은 재질별로 묶어 그려서 드로우콜을 줄였어요. 해상도는 기기 성능에 맞춰 자동으로 조절해요.

## 검증

헤드리스 Chromium(소프트웨어 WebGL)에서 다음을 자동으로 실행해 확인했어요.

- 선물 열기 → 별 8개 → 자정 연출 → 생쥐 군단 → 생쥐 왕 → 왕자 변신 → 별의 문 → 완료 화면(별 12/12, 제2장 해금). 페이지 오류 없음.
- 휴대폰 세로 화면(390×844, 터치): 타이틀·대화창·HUD 배치, 조이스틱 이동, 가로 스크롤 없음.

실제 휴대폰 GPU에서의 프레임레이트와 소리 출력은 확인하지 못했어요.
