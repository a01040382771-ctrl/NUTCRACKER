# NUTCRACKER — 클라라의 마법 여행

빈티지 유럽 동화책과 클래식 발레 무대를 섞은 3D 어드벤처예요. 클라라를 움직여 크리스마스 저택을 탐험하고, 장난감 왕국에서 흩어진 왕궁을 다시 조립하고, 눈송이의 숲에서는 왈츠에 맞춰 눈송이를 눌러 숲길을 열어요.

## 제1장 · 크리스마스 저택

1. 벨벳 커튼이 열리고 내레이션으로 시작해요.
2. 드로셀마이어 아저씨의 선물을 열면 호두까기 인형이 나와 클라라를 따라다녀요.
3. 마법의 별 8개를 모아요. 소파와 찻잔 테이블 위(점프), 트리를 도는 기차 화물칸, 벽난로 선반(알파벳 블록 계단), 오르골·흔들 목마·양말 속(살펴보기)에 숨어 있어요.
4. 자정이 되면 부엉이 시계가 울리고, 트리가 커지고, 호두까기 인형이 사람 크기로 깨어나요.
5. 생쥐 군단 5마리를 슬리퍼로 물리치고, 생쥐 왕의 왕관에 4번 맞혀 별을 되찾아요.
6. 호두까기 인형이 왕자로 변하고, 설탕 요정이 연 별의 문으로 들어가면 제2장이 열려요. 결과 화면에서 바로 이어 갈 수 있어요.

## 제2장 · 장난감 왕국

커다래진 트리 아래 장난감 왕국. 광장 한가운데에는 왕궁 대신 빛나는 설계도만 떠 있어요. 생쥐 왕이 흩뜨려 놓은 왕궁 조각 12개를 찾아 설계도대로 다시 세워요.

조각을 주우면 작은 모형이 되어 클라라 뒤를 줄지어 따라와요. 설계도 받침대에서 건축 모드로 들어가 조각을 끼우고, 한 단계를 다 맞추면 다음 구역의 문이 열려요.

| 단계 | 구역 | 조각과 찾는 방법 |
|---|---|---|
| 1 · 기단과 정문 | 왕궁 광장 | 기단(선물 상자 열기), 대리석 계단(알파벳 블록 꼭대기), 정문(분수 옆) |
| 2 · 날개와 기둥 회랑 | 기차 마을 | 왼쪽 날개(나무 상자를 밟고 장난감 가게 지붕으로), 오른쪽 날개(크레인 레버 당기기), 기둥 회랑(역에서 꼬마 기차 화물칸에 올라타기) |
| 3 · 탑과 아치 | 회전목마 광장 | 왼쪽 탑(돌아가는 회전목마 위), 오른쪽 탑(장난감 북을 밟고 튀어 올라 극장 옥상으로), 아치 발코니(생쥐 보초의 등불을 피해 진지 안쪽으로) |
| 4 · 돔과 꼭대기 별 | 오르골 정원 | 첨탑(소리 나는 피아노 건반 계단), 양파 돔(오르골 태엽 세 번 감기), 꼭대기 별(돌아가는 무대 위 발레리나 손끝, 점프) |

**건축 모드**

- 조각을 고르고, 설계도에서 그 조각이 들어갈 자리를 눌러요. 자리가 맞으면 조각이 그 위로 날아가요.
- 설계도와 방향이 다르면 돌리기 버튼으로 맞춰요. 방향까지 맞으면 딸깍 하고 끼워져요.
- 모양이 다른 자리는 튕겨 나와요. 세 번 틀리면 맞는 자리가 금빛으로 빛나요.
- 쌓는 순서가 있어요. 계단과 정문은 기단 위에, 첨탑은 돔 위에, 별은 첨탑 위에 올라가요.
- 생쥐 보초에게 들키면 진지 입구로 돌아가요. 다치지는 않아요.

마지막 별을 올리면 창문마다 불이 켜지고 불꽃이 터져요. 설탕 요정이 연 별의 문으로 들어가면 제3장이 열리고, 결과 화면의 **제3장으로 떠나기**로 바로 이어 갈 수 있어요.

**저장 · 이어하기**

- 한 단계를 끝낼 때마다 진행이 자동으로 저장돼요. 챕터 지도에서 **이어하기 · 제N단계**로 이어 가거나, **처음부터**로 새로 시작해요.
- 저장되는 건 끝낸 단계, 걸린 시간, 들킨 횟수예요. 단계 도중에 주운 조각은 저장되지 않아서, 이어하면 그 단계의 조각을 다시 찾아야 해요.
- 챕터를 끝내면 이어하기 기록은 지워지고 최고 기록만 남아요.
- 브라우저 저장소(localStorage)에 저장돼서 기기와 브라우저마다 따로예요. 제1장은 끝낸 기록만 저장돼요.

## 제3장 · 눈송이의 숲

퍼즐 없이 리듬만 있는 장이에요. 눈에 파묻힌 숲길을 눈송이 왈츠에 맞춰 열어요.

1. **눈꽃 요정의 부탁**: 별의 문을 지나면 눈 속에 길이 묻힌 숲이 나오고, 눈꽃 요정이 나타나 길을 열어 달라고 부탁해요.
2. **리듬 구간** (약 25초): 3·2·1 카운트 뒤 눈송이가 위에서 내려와요. 빛나는 원에 닿는 순간 그 줄을 눌러요. 판정은 **정확 / 좋음 / 놓침** 세 단계예요.
3. **점수 대신 진행도**: 눈송이 하나가 숲길 한 칸이에요. 정확하면 눈송이가 빙글 돌며 터지고, 칸이 환하게 열리고, 요정의 발자국이 생기고, 옆 등불이 켜져요. 좋음은 반쯤 열리고, 놓침은 눈에 덮인 채로 남아요. 놓쳐도 왈츠는 끝까지 이어져요.
4. **눈송이의 왈츠 (군무)**: 리듬 구간이 끝나면 요정이 문 앞 빈터로 초대하고, 발레 《호두까기 인형》 1막 마지막 장면처럼 눈송이 요정 12명이 군무를 춰요(아래 설명).
5. **피날레**: 군무가 끝나면 요정이 빙글 돌고, 남은 길이 한꺼번에 열리고, 제4장(과자의 왕국)으로 가는 문이 열려요. 결과 카드에는 열린 숲길 %, 정확한 눈송이 수, 좋음·놓침 수가 나와요(점수 대신 진행도).

### 눈송이의 왈츠 (군무)

- **무대**: 문 앞 8.5m의 둥근 빈터(반지름 5.4m). 빈터 안의 등불은 가장자리로 물러나 무대 조명처럼 둘러서요. 바닥에는 눈꽃 무늬 빛, 위에서는 은은한 빛기둥 셋, 무대 위로는 눈보라가 돌아요. 숲의 다른 나무와 장식은 그대로예요.
- **무용수**: 눈꽃 요정(솔로)과 흰 튜튜를 입은 눈송이 요정 12명. 눈송이 요정은 기존 요정 인형을 가볍게 만든 모양이고, 12명 모두를 몸 부위마다 한 번씩만 그려서(인스턴싱) 휴대폰에서도 가벼워요(화질 '부드럽게'나 메모리가 작은 기기에서는 8명).
- **안무** (64마디, 네 부분): 
  - 주제 20마디: 양쪽에서 부레로 들어와 한 줄로 서서 풍차처럼 돌며 발란세 → 큰 원
  - 변주 12마디: 눈송이 모양 별 대형, 안쪽·바깥쪽이 번갈아 아라베스크(돌림노래처럼)
  - 정적 13마디: 관객 쪽이 열린 말굽 대형으로 앉아 팔을 흩날리고, 요정은 눈을 잡듯 손을 뻗어요
  - 피날레 19마디: 서로 반대로 도는 두 원 → V자 대형에서 그랑 주테 → 요정을 향한 소용돌이 → 마지막 타블로
  - 끝나면 인사하고 다시 눈발이 되어 흩어져요. 대형이 바뀔 때는 이동 거리의 합이 가장 짧은 자리로 짝지어 서로 엇갈리지 않아요.
- **박자**: 모든 동작과 대형은 음악의 오디오 시계(마디·박)를 따라가요. 프레임이 떨어져도 박자는 맞고, 일시정지하면 음악과 춤이 같은 자리에서 함께 멈춰요.
- **건너뛰기**: 공연 중 오른쪽 아래 '공연 건너뛰기'를 누르면 마지막 장면으로 넘어가 피날레가 이어져요.

**군무 음악**
- **기본 연주**: 리듬 구간의 왈츠 주제를 E장조로 옮겨 변주·합창풍 정적·피날레로 이어 가는, 이 게임을 위해 새로 쓴 64마디 왈츠예요(WebAudio 합성). 차이콥스키 원곡 악보를 옮긴 것이 아니에요.
- **내 기기의 녹음**: 일시정지 메뉴의 '눈송이 왈츠 음원'을 누르고 녹음 파일을 고르면, 그 기기의 브라우저에만 저장되고 군무 때 그 녹음으로 공연해요. 파일은 서버나 저장소로 올라가지 않아요. 다시 누르면 기본 연주로 돌아가요.
  - 박자 지도는 한 녹음을 분석해서 만들었어요: 슬로바키아 라디오 교향악단·레나르드 지휘 「Waltz of the Snowflakes」(6분 35초, 6,380,697바이트)의 E장조 구간(325.6초~끝, 64마디). 다른 파일은 춤과 박자가 어긋나서 받지 않아요.
  - 이 녹음은 Naxos의 상업 음반이고, 받을 수 있었던 곳(YourClassical Daily Download)은 개인 감상용으로만 허락해요. 그래서 **게임 파일과 저장소에는 넣지 않았고, 넣으면 안 돼요**(공개 저장소·Pages에 올리면 재배포가 돼요).
  - 차이콥스키의 곡 자체는 퍼블릭 도메인이에요. 재배포가 허락된 원곡 녹음을 구하면 그 녹음용 박자 지도를 새로 만들어 기본 연주를 바꿀 수 있어요.

**타이밍**: 눈송이 위치와 판정은 프레임 시간이 아니라 `AudioContext.currentTime`(오디오 시계)으로 계산해요. 터치와 키 입력은 이벤트 시각을 오디오 시계로 바꿔서 판정하고, 브라우저가 알려 주는 출력 지연(`outputLatency`)도 반영해요. 일시정지하면 오디오 시계도 함께 멈추고, 화면이 가려지면 자동으로 일시정지해요.

**음악**: 기본은 눈송이 왈츠 풍으로 새로 만든 3/4박자 임시 트랙이에요(WebAudio로 합성하며, 차이콥스키 원곡 악보를 옮긴 것이 아니에요). 실제 음원을 쓰려면 아래 설정 파일의 `audio.url`에 경로를 적고 `bpm`과 `firstBeatSec`을 음원에 맞춰 주세요. 눈송이는 그 박자 위에 놓여요. 파일을 불러오지 못하면 임시 트랙으로 대신해요. 차이콥스키의 곡 자체는 저작권이 끝났지만 **녹음 파일은 연주자·음반사의 권리가 따로 있을 수 있으니**, 이용 조건이 분명한 음원(퍼블릭 도메인 또는 사용 허락을 받은 녹음)만 쓰세요.

**설정 파일 한 곳**: `src/js/17-snow-config.js`. 고친 뒤 `npm run build`를 하세요.

| 항목 | 기본값 | 뜻 |

제2장 무대는 처음 들어갈 때 만들어요. 그래서 첫 로딩이 짧고, 제2장을 처음 열 때 잠깐 준비 화면이 떠요.

## 빌드

```bash
npm run build        # 또는 node build.mjs
```

Node.js만 있으면 돼요. 설치할 패키지는 없어요. three.js 0.159.0은 jsDelivr CDN에서, 글꼴은 Google Fonts에서 불러와요.

## 테스트

`tools/`의 스크립트는 Playwright와 헤드리스 Chromium으로 게임을 끝까지 자동 진행해요.

```bash
mkdir -p .work && cp <three@0.159.0>/build/three.min.js .work/   # CDN 대신 쓸 로컬 사본
node tools/play-ch1.cjs    # 제1장 전체 + 결과 화면에서 제2장으로 이어 가기
node tools/play-ch2.cjs    # 제2장 전체 (조각 12개, 장치, 생쥐 보초, 건축 모드, 엔딩)
VIEW=mobile node tools/play-ch2.cjs   # 휴대폰 세로 화면
node tools/check-save.cjs  # 저장 → 새로고침 → 이어하기, 손상된 저장 무시, 클리어 시 삭제
node tools/check-rhythm.cjs   # 차트, 판정 경계값, 놓침 처리, 오디오 시계, 일시정지, 터치·키 입력, 설정값
node tools/play-ch3.cjs       # 제3장: 챕터 지도 → 리듬 → 일시정지 → 군무 → 피날레 → 결과·저장 → 다시 하기·나가기
node tools/dance-ch3.cjs      # 군무: 순서, 대형 8가지·간격, 일시정지, 소리, 건너뛰기, 성능 (LOCAL_WALTZ=파일 로 내 기기 녹음도)
VIEW=mobile node tools/dance-ch3.cjs   # 세로 폰 화면
node tools/mobile-ch3.cjs     # 제3장 휴대폰: 세로·가로·작은 화면 배치, 가로 스크롤 없음, 실제 터치 이벤트
node tools/chapters-flow.cjs  # 제1→2→3장 전환, 장면·카메라·오디오·HUD 정리
```

스크린샷은 `.work/shots/`에 저장돼요. (`.work/`는 커밋하지 않아요.)

## 만든 방식

- 캐릭터, 가구, 왕궁, 기차, 회전목마, 벽지, 양탄자, 얼굴까지 모두 코드로 그려요. 외부 3D 모델이나 이미지 파일은 없어요.
- 오르골 왈츠, 자정의 행진곡, 장난감 왕국의 폴카, 눈송이 왈츠 풍 임시 트랙, 효과음은 WebAudio로 합성해요. 샘플 파일은 없어요.
- 정적 소품은 재질별로 묶어 그려서 드로우콜을 줄였어요. 해상도는 기기 성능에 맞춰 자동으로 조절해요.
